# Code Standards & Guidelines

The coding guidelines for this project are maintained in [CONTRIBUTING.md](.github/CONTRIBUTING.md). Please read and follow that file.

- Comments only when necessary, this includes docstrings/jsdocs; don't add one just to restate what the name/code already say.
- Be concise, short README, no emojis.
- No extra feature, focus on what has been asked.
- Write in chunks to not overload your write tool!

## Docs

- Write prose docs as current-state fact, not as a log of how we got here. No "now automated", "I initially wrote X", "as discussed", just describe how it works today.
